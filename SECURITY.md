# Política de segurança / Security policy

**PT** — O APT4ALL só contém dados públicos (TLP:CLEAR) e scripts em Python com biblioteca padrão. Não há amostras de malware, credenciais nem procedimentos de ataque no repositório.
Encontrou algo assim, ou uma vulnerabilidade nos scripts ou nas páginas? Use **Security → Report a vulnerability** (aviso privado do GitHub). Não abra issue pública para isso.

**EN** — APT4ALL contains only public data (TLP:CLEAR) and standard-library Python scripts. No malware samples, credentials or attack procedures belong here.
If you find any, or a vulnerability in the scripts or pages, use **Security → Report a vulnerability** (GitHub private advisory) instead of a public issue.
