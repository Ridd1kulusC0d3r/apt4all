# Código de conduta / Code of Conduct

**PT** — Seja respeitoso, cite fontes e trate atribuição como hipótese, nunca como fato. Sem assédio, sem doxxing, sem pedidos de dados pessoais ou de material ofensivo. Mantenedores podem remover contribuições e bloquear quem violar estas regras.

**EN** — Be respectful, cite sources and treat attribution as a hypothesis, never a fact. No harassment, no doxxing, no requests for personal data or offensive material. Maintainers may remove contributions and block violators.
